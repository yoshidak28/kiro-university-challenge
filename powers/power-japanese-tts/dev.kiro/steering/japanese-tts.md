# 日本語音声読み上げの指針（Web Speech API）

ブラウザの `window.speechSynthesis` で日本語を読み上げるときは、以下に従う。
詳細な手順は本 Power の各スキル（`natural-japanese-voice` / `speech-text-rules` /
`speech-flow-control`）を参照すること。

## ボイス選択

- 読み上げは日本語（`utterance.lang = 'ja-JP'`）で行う。
- `getVoices()` は初回に空を返すことがあるため、`voiceschanged` イベントと
  リトライ（最大 5 回・200ms 間隔が目安）の両方でボイスを取得する。
- `lang` が `ja` で始まるボイスに絞り、「自然さ」でスコアリングして最良を選ぶ
  （既知の高品質ボイス名／`Enhanced`・`Neural` 等のキーワード／クラウド合成を加点）。
- 特定のボイス名の存在を前提にしない。候補が無ければブラウザ既定にフォールバックする。
- 用途に応じて話速（`rate`）・ピッチ（`pitch`）を調整する。未就学児・学習用途では
  やや遅め・やや高めが聞き取りやすい。

## 読み上げテキストの表記

- 画面表示用の文字列と読み上げ用の文字列は**別々の変数**として用意する。
- 読み上げ用は発音どおりに書く。助詞の「は」→「わ」、「へ」→「え」に直す。
- 語頭・語中の「は」「へ」（発音が変わらないもの）は置き換えない。単純な一括全置換はしない。

## 発話フロー制御

- 新しい発話の前に、進行中の発話を `cancel()` する。
- 読み上げ完了は `utterance.onend`、失敗は `utterance.onerror` で検知し、完了コールバックは
  二重発火をガードして 1 回だけ呼ぶ。
- 固定ディレイで次へ進めない。完了を待ちつつ、最小表示時間と最大待ち時間
  （フェイルセーフ）を併用して遷移する。
- Web Speech API 非対応ブラウザではサイレントにフォールバックし、完了コールバックは
  非同期で必ず呼んで画面遷移を止めない。音声以外の機能は動作を継続する。
