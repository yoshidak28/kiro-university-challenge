# 読み上げ用テキストの表記ルール

音声合成に渡す文字列は、**発音どおり**に書く必要がある。日本語の助詞「は」「へ」は
文字どおり読むと不自然になるため、読み上げ用だけ発音に合わせて置き換える。

## 原則

- **画面に表示する文章**：通常の正書法のまま（助詞の「は」「へ」はそのまま）。
- **読み上げ用の文章**：発音どおりに書く。特に助詞を次のように置き換える。
  - 助詞の「は」 → 「わ」
  - 助詞の「へ」 → 「え」

置き換えるのは **助詞として「わ」「え」と発音される「は」「へ」だけ**。
語頭・語中の「は」「へ」（発音が変わらないもの）は置き換えない。

## 例

| 用途 | 表記 |
|---|---|
| 画面表示 | `こたえは「あ」だよ！` |
| 読み上げ | `こたえわ「あ」だよ！` |
| 画面表示 | `つぎへ すすもう` |
| 読み上げ | `つぎえ すすもう` |

置き換えない例（語頭・語中）:

| 用途 | 表記 |
|---|---|
| 画面表示・読み上げ共通 | `はな`（花）… 語頭の「は」はそのまま |
| 画面表示・読み上げ共通 | `へや`（部屋）… 語頭の「へ」はそのまま |

## 手順

### 1. 表示用と読み上げ用の変数を分ける

同じ文を使い回さず、2 つの変数を用意する。

```js
let feedbackMessage; // 画面表示用（正書法）
let speechMessage;   // 読み上げ用（発音どおり）

feedbackMessage = 'こたえは「' + char + '」だよ！';
speechMessage   = 'こたえわ「' + char + '」だよ！';
```

### 2. 助詞だけを置き換える（機械的な一括置換はしない）

「は」「へ」を単純に全置換すると、`はな`（花）や `へや`（部屋）まで壊れる。
助詞かどうかは文脈で判断する必要があるため、**読み上げ用の文を書く時点で
人が助詞を見極めて「わ」「え」に直す**のが安全。

新しく読み上げ文を追加するときも、助詞の「は」「へ」を含むなら必ず
「わ」「え」に直してから `speak()` に渡す。

### 3. 読み上げる

```js
feedbackArea.textContent = feedbackMessage; // 画面には正書法
SpeechSynthesizer.speak(speechMessage);      // 音声には発音どおり
```

## チェックリスト

- [ ] 表示用（正書法）と読み上げ用（発音どおり）を別の変数にしているか
- [ ] 読み上げ用の助詞「は」→「わ」、「へ」→「え」に直したか
- [ ] 語頭・語中の「は」「へ」を誤って置き換えていないか
- [ ] 単純な一括全置換に頼っていないか（助詞判定は文脈依存）
