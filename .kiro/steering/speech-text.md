# 読み上げ（音声）テキストの表記ルール

このプロジェクトでは、音声合成（Web Speech API / SpeechSynthesizer）に渡す文字列と、
画面に表示する文字列を区別して扱う。

## 原則

- **画面に表示する文章**：通常の正書法のまま書く（助詞の「は」「へ」はそのまま）。
- **読み上げ用の文章**：発音どおりに書く。特に助詞を次のように置き換える。
  - 助詞の「は」 → 「わ」
  - 助詞の「へ」 → 「え」

助詞以外（語頭・語中の「は」「へ」など、発音が変わらないもの）は置き換えない。
あくまで **助詞として「わ」「え」と発音される「は」「へ」のみ** を対象とする。

## 例

| 用途 | 表記 |
|---|---|
| 画面表示 | `こたえは「あ」だよ！` |
| 読み上げ | `こたえわ「あ」だよ！` |
| 画面表示 | `つぎへ すすもう` |
| 読み上げ | `つぎえ すすもう` |

語頭・語中の例（置き換えない）:

| 用途 | 表記 |
|---|---|
| 画面表示・読み上げ共通 | `はな`（花）… 語頭の「は」はそのまま |
| 画面表示・読み上げ共通 | `へや`（部屋）… 語頭の「へ」はそのまま |

## 実装上の指針

- 画面表示用のメッセージ（例: `feedbackMessage`）と読み上げ用のメッセージ
  （例: `speechMessage`）は別々の変数として用意し、読み上げ用のみ助詞を置き換える。
- 新しく読み上げ用の文章を追加する場合も、助詞の「は」「へ」を含むなら
  必ず「わ」「え」に直してから `SpeechSynthesizer.speak()` に渡すこと。
